# Scripts

| Script | Purpose |
|--------|---------|
| `mach4_work_pose_publisher.lua` | Mach4 PLC: publish the work DRO and accept load/run commands |
| `mach4_home_bc.txt` | B/C home script used by `python -m app cnc home` |
| `mach4_scan_head.txt` | Head-scan script used by `python -m app cnc scan` |
| `test_read_obj.py` | Check that an OBJ still has UVs and its MTL/JPG |

Run from the repository root. Landmark capture is documented in [docs/RECORD_PM.md](../docs/RECORD_PM.md).
